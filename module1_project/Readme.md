# LOSTLEAF BOOK TRACKER

## PROBLEM STATEMENT
In many public high schools where textbooks are donated by the government, students tend to lose these books due to different circumstances. Students with lost books search for them effortlessly without succeeding. At the end, they are charged for the lost books at a **70% interest** which brings frustration to both the student and the parent or guardian who is catering for the fees. 

Currently there is no system to:
- Track books using unique codes.
- Report lost books in a centralized way.
- Allow owners to recover lost books efficiently
## PROPOSED SOLUTION 
My proposed solution to this problem is coming up with a website that allows students to:
- Report lost textbooks using the book's unique code
- View found textbooks and their codes

This system will simplify the process of recovering lost textbooks and ensures lost books are returned to their rightful owners. 
## TECHNOLOGIES USED

- HTML
- CSS 
- Optional for future improvement(Javascript)

## PLATFORM PAGES

- **HOME PAGE** which entails basic introduction information which the user might need to know which will also entail navigation links
- **REPORT LOST PAGE** Form where users enter details of a lost textbook.
- **REPORT FOUND PAGE** Form to submit details of a found textbook.
- **LISTINGS PAGE** Displays all reported lost and found books.
- **CONTACT PAGE** Allows users to reach out for support.
